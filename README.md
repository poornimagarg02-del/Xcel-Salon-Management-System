
# Xcel Salon Management System

A web-based Salon Management System designed to simplify and streamline daily salon operations, appointment scheduling, customer management, and service administration.

## 📌 Project Overview

Xcel Salon Management System is a web application developed to digitize salon operations and improve the overall management experience for salon administrators and customers.

The system aims to reduce manual work, organize salon-related information, and provide a structured platform for managing appointments, services, and customer records.

## ✨ Key Features

- **Appointment Management:** Manage and organize salon appointments.
- **Customer Management:** Maintain customer information and records.
- **Service Management:** Manage salon services and their details.
- **Admin Management:** Manage salon operations through an administrative interface.
- **User-Friendly Interface:** Simple and organized interface for easy navigation.
- **Centralized Management:** Keep salon-related information organized in one system.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/poornimagarg02-del/Xcel-Salon-Management-System.git
```

### 2. Navigate to the Project Directory

```bash
cd Xcel-Salon-Management-System
```

### 3. Set Up the Local Server

- Install XAMPP or WAMP.
- Move the project folder into the server's web directory.
- Start Apache and MySQL.

### 4. Configure the Database

- Open phpMyAdmin.
- Create a database for the project.
- Import the project's SQL database file.
- Update database connection settings in the configuration file.

### 5. Run the Application

Open your browser and visit:

```text
http://localhost/Xcel-Salon-Management-System/
```
